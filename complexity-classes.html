Section 4

The complexity classes PR and NPR and reductions

Keming Meng · 15-455 Project Writeup

We first start by defining the complexity class PR.

Definition 9. We say that a language L is in PR iff there exists a BSS machine M computing the characteristic function of L such that for any x in the input space, we have that TM(x) ≤ p(|x|), for some polynomial p, where |x| denotes the length of the input x, much the same as the Turing Machine definition of P.

Definition 10. Similarly, we say that a language L is in NPR iff there exists a polynomial time verifier BSS machine V such that for all x ∈ L, there is y ∈ R∗ such that V (x, y) = 1, and |y| ≤ p(|x|) for some polynomial p, and for all x ∉ L, for all y ∈ R∗, V (x, y) = 0.

Given these classes of problems, we want a good way of comparing their difficulties. In particular, we care about being able to say if a problem is as hard as another. To formalize this notion, we utilize reductions. Once again in analogy with Turing Machines, we utilize polynomial time mapping reductions.

In particular, for languages K, L ∈ P or NP, we say that K reduces to L if there exists a polynomial-time computable φ such that x ∈ K ⇐⇒ φ(x) ∈ L.
