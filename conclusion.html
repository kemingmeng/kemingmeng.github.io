Section 7

Conclusion and Acknowledgements

Keming Meng · 15-455 Project Writeup

As you can see, there is a rich theory that can be developed if we allow stronger machines with access to real numbers. One can go even further by defining all the complexity classes we have learned so far in our course with real numbers. Additionally, the theory discussed in this project can be generalized for rings as well, which allows for us to understand computation from an algebraic viewpoint.

All of the content discussed in this project is based on the content found from chapters 2-5 of the book ”Complexity and Real Computation” by Lenore Blum, Felipe Cucker, Michael Shub, and Steve Smale. In particular, most of the definitions are from this book, and especially the definition of the \(\mathrm{SA\text{-}FEAS}\) language is quoted from the book.
