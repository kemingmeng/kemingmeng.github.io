Section 5

Register Equations

Keming Meng · 15-455 Project Writeup

Now with these complexity classes in hand, it is natural to wonder if there is a representative problem to consider in these classes. In particular, if we are concerned with whether PR = NPR, searching for and understanding NPR problems is critical.

To start, we will note some features of BSS machines that will be helpful in generating NPR complete problems.

We first look towards finding further ways to characterize halting.

To do so, first fix a BSS machine M, fix a time T, and let us look at inputs x with lengths all less than some bound. Note that we can reduce M to a finite dimensional BSS machine since we are looking at a finite stopping time for a single input. Also assume that M has N nodes, and that its active state space S = Rn.

We now define the next node map

β : [N] × S → [N]

by simply sending a node-state pair to its next node, and define the next state map

g : [N] × S → S

accordingly as well. For the output node, we let the next node map and next state map be the identity.

Then, if we let I be the initial linear map computed from the input node for our finite-dimensional representation of our BSS machine, we have that x ∈ ΩM,T iff there is a sequence of nodes α0, . . . , αT and sequence of states x0, . . . , xT satisfying:

α0 = 1, x0 = I(x)

and for all k ≤ T, k ≥ 1, we have that

αk = β(αk−1, xk−1)
xk = g(αk−1, xk−1)
αT = N.

We can also enforce the output value by placing restrictions on xTi. For example, to ensure that the output value is 1, we can enforce xT1 = 1, xT0 = 1, xT−1 = 0

This gives a nice mathematical description for halting, however to get an NP complete language out of this, we want more structure within these equations. Notably, thus far we have been looking at polynomial equations, so it would be convenient if we could somehow make the above equations into a system of polynomial equations and inequalities over R.

A first step towards doing so, is by defining a modified version of β and g. If we represent the ith node by the vector ei, the ith standard basis vector, then we can represent β and g effectively using β̂, ĝ, where β̂ : RN × S → RN, and ĝ : RN × S → S, where

β̂(α, x) = ΣNi=1 αi eβ(i,x)

ĝ(α, x) = ΣNi=1 αi g(i, x).

Thus, our equations now become:

α0 = e1, x0 = I(x)

and for all k ≤ T, k ≥ 1, we have that

αk = β̂(αk−1, xk−1)
xk = ĝ(αk−1, xk−1)
αT = eN.

These are often called the time-T register equations for M, and are frequently denoted as

RT (x, z)

as the equations are in the variables (x1, . . . , xn), and z = (α0, x0, . . . , αT , xT ).

Note now however, that these equations are not yet fully described with polynomials. In particular, β̂ is a problem when we reach a branch node, and ĝ is rational rather than polynomial.

First, note that the equations with ĝ can easily be fixed to be polynomial by clearing out the denominators and ensuring the denominators are nonzero, which adds O(T) equations. Moreover, the degree of the equations is increased by at most a factor of N times the highest degree polynomial in any of the rational functions, since in the size N sum of ĝ, to get a common denominator, we can require up to N times the highest degree polynomial degree.

To fix the equations with β̂, we can decompose β̂. To do so, let β+, β− be equal to β for non branching-nodes, and then equal to the appropriate branch-node when computing at the branch node. Then, we can define

β̂±(α, x) = ΣNi=1 αi eβ±(i,x)

and this allows for us to obtain a semi-algebraic system, by turning

αk = β(αk−1, xk−1)

into

(αk = β̂−(αk−1, xk−1) ∧ (xk−1)1 < 0) ∨ (αk = β̂+(αk−1, xk−1) ∧ (xk−1)1 ≥ 0)

for all k ≤ T, k ≥ 1.

This now is a semi-algebraic system, as everything is now either a polynomial inequality or equality.

We now provide some bounds on the number of equations and inequalities we have, the degrees of the polynomials in the equations, and the number of variables.

Let m be the dimension of the state space for the finite-dimensional BSS machine we have reduced to. Then, the number of equations for the equations with ĝ is mT, m equations since xi is m dimensional, with T many of these m equations for each step. The number of equations and inequalities involving β̂± is 2NT + 2T, 2T for the inequalities, 2N equations for each time step, and T time steps. There are then a remaining N equations for ensuring that αT = eN, and N + m equations for checking the initial node and state. Then, the highest degree is bounded by N times the highest degree polynomial in any of the rational functions, by our claim before.

Finally, the number of variables is at most n + (T + 1)(N + m), as there are n for x, and (T + 1)(N + m) for z.
