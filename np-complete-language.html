Section 6

An \(NP_{\mathbb R}\) Complete Language

Keming Meng · 15-455 Project Writeup

We are now ready to present an \(NP_{\mathbb R}\) complete language for our BSS machines.

First, define

\[\mathbb R[x_1,\ldots,x_n]\]

to be the real polynomials with the variables \(x_1\), . . . , \(x_n\).

Definition 11. The language semi-algebraic feasibility, called

\[\mathrm{SA\text{-}FEAS}=\{(\varphi_1,\ldots,\varphi_n):\varphi_j=(f_{j1},\ldots,f_{jm},g_{j1},\ldots,g_{jk}),\ f_{ji},g_{j\ell}\in\mathbb R[x_1,\ldots,x_p]\}\]

where there is some \(x\) such that

\[\varphi(x)=f_{j1}>0\ \vee\ \cdots\ \vee\ f_{jm}>0\ \vee\ g_{j1}=0\ \vee\ \cdots\ \vee\ g_{jk}=0\]

is true for each \(1\le j\le n\). (This definition is adapted/quoted/paraphrased from the book ”Complexity and Real Computation” which referenced in the acknowledgments.)

Remark 3. One might wonder how we encode instances of \(\mathrm{SA\text{-}FEAS}\). The primary worry is in encoding the polynomials. To do so, we can first note that for any given polynomial with a certain degree over a certain number of variables, we can impart a total order on the monomials. Using such a total order, we can then for each polynomial give its degree, the number of variables it has, and the coefficients on its monomials one by one.

Remark 4. The semi-algebraic system obtained from the register equations in the previous section can be turned into the form of input for \(\mathrm{SA\text{-}FEAS}\) in polynomial time.

Now, we claim that \(\mathrm{SA\text{-}FEAS}\) is a an \(NP_{\mathbb R}\) complete language.

The fact that \(\mathrm{SA\text{-}FEAS}\) is in \(NP\) is clear by the fact that as a proof string, we can simply provide a value of \(x\) that witnesses each of the \(\phi_j\) being satisfied.

We now prove the main theorem that remains.

Theorem 2. \(\mathrm{SA\text{-}FEAS}\) is \(NP_{\mathbb R}\) hard.

Proof. To show the above, we reduce any \(NP_{\mathbb R}\) problem to \(\mathrm{SA\text{-}FEAS}\) via a mapping reduction. First, fix a language \(L\in NP_{\mathbb R}\). We know then that \(x\in L\) iff there is a polynomial-time verifier \(V\), and a polynomial \(p\) such that there is some \(y\) with \(|y|\le p(|x|)\), such that \(V\) (\(x\), \(y\)) accepts. Let \(T=q(|x|)\) bound the time complexity of \(V\). Now, consider the time-\(q(|x|)\) register equations for \(V\) with input (\(x\), \(y\)) and output 1, with \(x\) fixed from before. Using the main result of the previous section, these register equations can be reduced to a semi-algebraic system with polynomial size in |\(x\)|, since the time is polynomial in |\(x\)|, the size of \(y\) is at most polynomial in |\(x\)|, and the degree of the polynomials in the semi-algebraic system is constant. Call this semi-algebraic system \(\phi_T(x,y,z)\). Then, note that the map sending \(x\mapsto\phi_T(x,y,z)\) with the value of \(x\) plugged in and with \(\phi_T(x,y,z)\) in the form of \(\mathrm{SA\text{-}FEAS}\) is polynomial time computable as we discussed previously, and is a mapping reduction reducing \(L\) to \(\mathrm{SA\text{-}FEAS}\), as \(x\in L\) iff there is some \(y\) within the polynomial bounds such that the register equations are satisfied in time \(T\), which occurs iff \(\phi_T(x,y,z)\) is feasible, and so we are done.
