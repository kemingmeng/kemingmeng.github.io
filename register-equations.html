Section 5

Register Equations

Keming Meng · 15-455 Project Writeup

Now with these complexity classes in hand, it is natural to wonder if there is a representative problem to consider in these classes. In particular, if we are concerned with whether \(P_{\mathbb R}\) = \(NP_{\mathbb R}\), searching for and understanding \(NP_{\mathbb R}\) problems is critical.

To start, we will note some features of BSS machines that will be helpful in generating \(NP_{\mathbb R}\) complete problems.

We first look towards finding further ways to characterize halting.

To do so, first fix a BSS machine \(M\), fix a time \(T\), and let us look at inputs \(x\) with lengths all less than some bound. Note that we can reduce \(M\) to a finite dimensional BSS machine since we are looking at a finite stopping time for a single input. Also assume that \(M\) has \(N\) nodes, and that its active state space \(S=\mathbb{R}^{n}\).

We now define the next node map

\[\beta:[N]\times S\to[N]\]

by simply sending a node-state pair to its next node, and define the next state map

\[g:[N]\times S\to S\]

accordingly as well. For the output node, we let the next node map and next state map be the identity.

Then, if we let \(I\) be the initial linear map computed from the input node for our finite-dimensional representation of our BSS machine, we have that \(x\in\Omega_{M,T}\) iff there is a sequence of nodes \(\alpha^0\), . . . , \(\alpha^T\) and sequence of states \(x^0\), . . . , \(x^T\) satisfying:

\[\alpha^0=1,\quad x^0=I(x)\]

and for all \(k\le T,\ k\ge1\), we have that

\[\begin{aligned}\alpha^k&=\beta(\alpha^{k-1},x^{k-1})\\ x^k&=g(\alpha^{k-1},x^{k-1})\\ \alpha^T&=N.\end{aligned}\]

We can also enforce the output value by placing restrictions on \(x_i^T\). For example, to ensure that the output value is 1, we can enforce \(x^T_1=1,\ x^T_0=1,\ x^T_{-1}=0\)

This gives a nice mathematical description for halting, however to get an \(NP\) complete language out of this, we want more structure within these equations. Notably, thus far we have been looking at polynomial equations, so it would be convenient if we could somehow make the above equations into a system of polynomial equations and inequalities over \(\mathbb R\).

A first step towards doing so, is by defining a modified version of \(\beta\) and \(g\). If we represent the ith node by the vector \(e_i\), the ith standard basis vector, then we can represent \(\beta\) and \(g\) effectively using \(\hat\beta\), \(\hat g\), where \(\hat\beta:\mathbb{R}^N\times S\to\mathbb{R}^N\), and \(\hat g:\mathbb{R}^N\times S\to S\), where

\[\begin{aligned}\hat\beta(\alpha,x)&=\sum_{i=1}^{N}\alpha_i e_{\beta(i,x)}\\[6pt]\hat g(\alpha,x)&=\sum_{i=1}^{N}\alpha_i g(i,x).\end{aligned}\]

Thus, our equations now become:

\[\alpha^0=e_1,\quad x^0=I(x)\]

and for all \(k\le T,\ k\ge1\), we have that

\[\begin{aligned}\alpha^k&=\hat\beta(\alpha^{k-1},x^{k-1})\\ x^k&=\hat g(\alpha^{k-1},x^{k-1})\\ \alpha^T&=e_N.\end{aligned}\]

These are often called the time-\(T\) register equations for \(M\), and are frequently denoted as

\[R_T(x,z)\]

as the equations are in the variables \((x_1,\ldots,x_n)\), and \(z\) = \((\alpha^0,x^0,\ldots,\alpha^T,x^T)\).

Note now however, that these equations are not yet fully described with polynomials. In particular, \(\hat\beta\) is a problem when we reach a branch node, and \(\hat g\) is rational rather than polynomial.

First, note that the equations with \(\hat g\) can easily be fixed to be polynomial by clearing out the denominators and ensuring the denominators are nonzero, which adds \(O(T)\) equations. Moreover, the degree of the equations is increased by at most a factor of \(N\) times the highest degree polynomial in any of the rational functions, since in the size \(N\) sum of \(\hat g\), to get a common denominator, we can require up to \(N\) times the highest degree polynomial degree.

To fix the equations with \(\hat\beta\), we can decompose \(\hat\beta\). To do so, let \(\beta^{+}\), \(\beta^{-}\) be equal to \(\beta\) for non branching-nodes, and then equal to the appropriate branch-node when computing at the branch node. Then, we can define

\[\hat\beta^{\pm}(\alpha,x)=\sum_{i=1}^{N}\alpha_i e_{\beta^{\pm}(i,x)}\]

and this allows for us to obtain a semi-algebraic system, by turning

\[\alpha^k=\beta(\alpha^{k-1},x^{k-1})\]

into

\[\bigl(\alpha^k=\hat\beta^{-}(\alpha^{k-1},x^{k-1})\ \wedge\ (x^{k-1})_1<0\bigr)\ \vee\ \bigl(\alpha^k=\hat\beta^{+}(\alpha^{k-1},x^{k-1})\ \wedge\ (x^{k-1})_1\ge0\bigr)\]

for all \(k\le T,\ k\ge1\).

This now is a semi-algebraic system, as everything is now either a polynomial inequality or equality.

We now provide some bounds on the number of equations and inequalities we have, the degrees of the polynomials in the equations, and the number of variables.

Let \(m\) be the dimension of the state space for the finite-dimensional BSS machine we have reduced to. Then, the number of equations for the equations with \(\hat g\) is \(mT\), \(m\) equations since \(x^i\) is \(m\) dimensional, with \(T\) many of these \(m\) equations for each step. The number of equations and inequalities involving \(\hat\beta^{\pm}\) is \(2NT+2T\), \(2T\) for the inequalities, \(2N\) equations for each time step, and \(T\) time steps. There are then a remaining \(N\) equations for ensuring that \(\alpha_T\) = \(e_N\), and \(N+m\) equations for checking the initial node and state. Then, the highest degree is bounded by \(N\) times the highest degree polynomial in any of the rational functions, by our claim before.

Finally, the number of variables is at most \(n+(T+1)(N+m)\), as there are \(n\) for \(x\), and (\(T+1\))(\(N+m\)) for \(z\).
